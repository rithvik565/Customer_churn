Customer Churn Analysis
Project Overview
This project explores customer churn data to understand why customers leave and identify key factors influencing retention. By analyzing subscription plans, support interactions, and demographic data, we extract insights to help reduce churn and improve customer loyalty.
Key Findings
 Plan Type: The Basic plan shows the highest churn rate (60%), while the Premium plan has the lowest.
 Support Escalation: All customers with explicitly recorded support escalation churned.
 State-Level Trends: Karnataka and Meghalaya have higher state-level churn rates.
 High-Risk Segment: The score-based high-risk segment contains six customers, all of whom churned.
Technologies Used
 Python (Pandas, NumPy, Matplotlib, Seaborn)
 Microsoft Excel
 Visual Studio Code
Usage
This repository contains the Python scripts for data cleaning and exploratory analysis, the raw dataset, and the detailed analytics report in PDF format.
